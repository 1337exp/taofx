# taofx

Редактор и рантайм эффектов на three.js (TSL). Прототип: граф нод → TSL → материал.

```bash
npm install
npm run dev     # http://localhost:5173: слева JSON графа, справа превью
npm test
```

## Как устроено

- `src/graph/` — ядро без Vue: типы графа, реестр нод, `resolveTypes` (вывод `gen`-типов, как genType в GLSL) и `compile` (граф → значения TSL, каждая нода строится один раз).
- `src/nodes/<категория>/<имя>.ts` — определения нод, подхватываются автоматически. У ноды вместо `run` метод `build`: он строит узлы TSL, а не исполняется.
- `src/preview/` — three.js `WebGPURenderer` (сам откатывается на WebGL2) и меш с материалом из графа.
- Типы пинов: `float`, `vec2`, `vec3`, `vec4`, `color`, плюс `gen`. Связь разрешена между одинаковыми размерами и из `float` в любой тип (растяжение); сужение запрещено.
